# TanymTor frontend

По умолчанию работает локальное демо без бэкенда и PostgreSQL.

Запуск из корня репозитория: `npm run dev`. Сборка фронтенда: `npm run build --prefix frontend`.

Учитель: `teacher@tanymtor.kz` / `teacher123` (кнопка «Заполнить демо-аккаунт»).
Администратор: `/admin/login`, `admin@tanymtor.kz` / `admin123`.

Классы, уроки, отметки, рассадка, импортированные оценки, действия по сигналам и
демо-аккаунты сохраняются в localStorage текущего браузера. Очистка данных сайта
удаляет их. Другие браузеры и устройства имеют отдельные данные. Это демонстрация,
а не защищённая система с серверной авторизацией. Регистрируйте только пробные
аккаунты; их можно одобрить в демо-админке в том же браузере.

На Vercel используйте Root Directory `frontend` и стандартную сборку Next.js.
Включите доступ к файлам вне Root Directory: фронтенд использует расчёты из `shared/src`.
Локальный режим включён по умолчанию; при необходимости явно задайте
`NEXT_PUBLIC_DATA_MODE=local` для Production и Preview. После публикации изменений
нужна новая сборка. В локальном режиме запросов к `/api` нет, API_PROXY_TARGET не используется.

Для возврата к серверу задайте `NEXT_PUBLIC_DATA_MODE=api` и
`API_PROXY_TARGET=https://адрес-бэкенда` (без `/api` и завершающего слеша), затем
пересоберите сайт. Локальные данные автоматически на сервер не переносятся;
локальная и серверная сессии хранятся отдельно.

Проверка локальных сценариев из корня: `node_modules/.bin/tsx --tsconfig frontend/tsconfig.json --test frontend/tests/local-api.test.ts`.
